# Dokumentacja funkcjonalności

Jeden plik opisuje jeden spójny obszar produktu. Dokument powinien zawierać cel, zasady dostępu, najważniejsze ścieżki użytkownika, stan wdrożenia oraz istotne decyzje techniczne.

Zanim utworzysz nowy dokument, wyszukaj, czy zakres nie jest już opisany. Jeżeli użytkownik poda nazwę dokumentu na początku zadania, kontynuuj wskazany plik zamiast zakładać nowy.

Aktualne dokumenty:

- [private-shared-gallery.md](private-shared-gallery.md) — albumy dostępne przez link i ich dedykowany widok.
- [admin-bulk-upload.md](admin-bulk-upload.md) — kolejka masowego uploadu zdjęć w panelu admina oraz batchowy upload mediów gościa.
