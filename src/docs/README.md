# Dokumentacja Marryly

Ten katalog jest wspólnym, trwałym źródłem kontekstu projektu. Nie zawiera sekretów ani lokalnej konfiguracji środowiska.

- [project-guide.md](project-guide.md) — czym jest aplikacja, jej aktualna architektura, struktura repozytorium i sposób lokalnej pracy.
- [current-status.md](current-status.md) — krótki indeks statusów i odnośników do dokumentacji funkcjonalności.
- [features/](features/) — osobne dokumenty funkcjonalności; szczegóły implementacji i decyzje produktowe.
- [architecture/target-architecture.md](architecture/target-architecture.md) — docelowy kierunek rozwoju backendu; nie opisuje jeszcze w pełni aktualnego wdrożenia.

Każdy nowy agent Codex pracujący w tym repozytorium dostaje wskazówkę z [AGENTS.md](../AGENTS.md), aby najpierw przeczytać dwa pierwsze dokumenty.
